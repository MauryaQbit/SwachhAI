# SwachhAI — 3-Minute Demo Script

## 0:00–0:20 — Landing (`/`)
"Garbage problems are observed but not converted into structured, prioritized
intelligence." Show headline, See → Analyze → Prioritize → Act cards.

## 0:20–0:50 — Upload (`/analyze`)
Upload a waste photo, set coarse area (e.g. *Laxmi Nagar, Delhi*), hit **Analyze waste**.
Point at staged progress (UX indicators while the model responds).

## 0:50–1:20 — AI analysis
Read the card: mixed waste · HIGH · risks · segregation guidance. Note the hedged
language (*appears to, estimated*).

## 1:20–1:40 — Priority + why
Priority **82/100 CRITICAL** → open *Why this priority?* breakdown. State: "AI gives
signals; deterministic code owns the score — SwachhAI prototype priority model."

## 1:40–2:00 — Create report
**Create report → Dashboard**. Note server recomputes priority; report gets
`ASSESSED` status.

## 2:00–2:20 — Dashboard / Map / Hotspots
KPIs from live data (demo entries labeled). Open `/map`: colored markers, top hotspot
*Laxmi Nagar*. "Observed hotspots — not official figures."

## 2:20–2:40 — Assistant
Ask: *"Which area needs the most attention?"* → grounded answer with numbers. Ask
something unsupported → refusal line.

## 2:40–3:00 — Impact + pilot
Proposed pilot: citizens/NGOs → SwachhAI triage → action queue → cleanup → status.
Limitations honest: estimates, prototype model, demo data, human verification required.
